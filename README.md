# 国中宝 - 招投标平台移动应用

## 项目简介

国中宝是一个基于 uni-app 框架开发的综合性招投标平台移动应用，支持 Android、iOS、H5 和微信小程序多端部署。该平台为用户提供了一个便捷的招投标信息发布、浏览、投标和交易的综合服务平台，涵盖工业制造、生活服务、房产汽车等多个领域。

## 技术栈

- **框架**: uni-app 3.x (Vue 3)
- **状态管理**: Pinia 2.x
- **构建工具**: Vite 5.x
- **UI组件**: @dcloudio/uni-ui
- **加密**: crypto-js
- **实时通信**: WebSocket
- **语音识别**: 百度语音 API

## 核心功能

### 1. 用户系统
- 用户注册、登录、找回密码
- 实名认证
- 个人信息管理
- 账号安全设置
- 账号注销

### 2. 项目管理
- 项目发布（支持16大类目，100+子分类）
- 项目列表浏览与筛选
- 项目详情查看
- 我的项目管理

### 3. 投标系统
- 需求集市浏览
- 在线投标
- 我的投标记录
- 投标状态跟踪

### 4. 订单管理
- 订单列表
- 订单详情
- 订单状态跟踪

### 5. 消息通讯
- 实时聊天（WebSocket）
- 消息中心
- 通知推送
- 语音消息支持

### 6. 其他功能
- 视频播放
- 意见反馈
- 用户协议与隐私政策
- 关于我们

## 项目分类

平台支持以下16大业务分类：

1. **工业标单需求** - 机械加工、模具检具、自动化、机床设备等
2. **餐饮美食需求** - 中餐、地方菜、外国餐厅
3. **休闲娱乐需求** - 洗浴按摩、KTV酒吧、体育场馆、影院演出
4. **手机需求** - 各品牌手机、电脑、平板
5. **家电需求** - 电视、冰箱、洗衣机、空调等
6. **家居需求** - 家具、家纺、灯具装饰、建材
7. **汽车需求** - 新能源汽车、燃油车、货运车
8. **房产需求** - 新房、二手房、租房、中介服务
9. **服装鞋帽需求** - 男装、女装、设计师定制
10. **家装装修需求** - 整包装修、分包装修、绿化工程
11. **生活服务需求** - 酒店、出行、旅游、保险、教育培训
12. **二手物品需求** - 二手车、手机、电脑、家电、家具
13. **人力服务需求** - 企业直聘、技工兼职、服务型人员
14. **医疗就医需求** - 医疗服务、医疗用品、求诊
15. **艺术品奢饰品需求** - 珠宝腕表、箱包配饰、绘画雕塑、古董
16. **交友相亲需求** - 按性别分类的交友服务
